# Platform: Android 7.0+ (phones and tablets)

A Capacitor app per `mobile-common.md`. Read that file first.

## Project

- App id `org.reminderfoxagain.app`, name **ReminderFoxAgain**, version name `0.8.1`, version code `801`.
- `minSdkVersion 24`, `compileSdkVersion`/`targetSdkVersion` = the level Google Play currently requires (35 or newer).
  JDK 21, the Android Gradle Plugin from the Capacitor 7 template, Gradle wrapper committed.
- Layout: `package.json` (Capacitor, plugins, esbuild, Playwright for tests), `capacitor.config.json`
  (`webDir: "www"`, `android.allowMixedContent: false`, `server.androidScheme: "https"`), `www/` (built), `android/`
  (generated by `npx cap add android`, then edited), `src/` (shared), `test/`, `tools/`.
- `www/index.html` is `src/ui/index.html` with `mobile.css`, `mobile.js` and `host.js` added before `common.js`. There
  is no preload: `host.js` sets `window.rf`. The alarm window is not a separate page; `alarm.js` is mounted inside the
  Due now sheet (factor its rendering into a function that takes a container).

## Native resources

- Launcher: adaptive icon from `reference/assets/android/adaptive-foreground-432.png` +
  `adaptive-background-432.png` (`mipmap-anydpi-v26/ic_launcher.xml`, also `ic_launcher_round`), and the legacy
  `mipmap-*/ic_launcher.png`.
- Notification small icon: `drawable-*/ic_stat_reminderfoxagain.png` (white on transparent); accent colour `#e26e26`.
- Sounds: `res/raw/chime.wav`, `bell.wav`, `marimba.wav`, `beeps.wav`, `clock.wav` (from `reference/assets/sounds/`).
- Splash: background `#fbf8f4` (dark `#1d1712`), the icon centred.

## Notifications and permissions

- `AndroidManifest.xml`: `POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM`, `RECEIVE_BOOT_COMPLETED`, `VIBRATE`,
  `WAKE_LOCK`. No `USE_FULL_SCREEN_INTENT`.
- Channels, created on start:
  - `alarms-<tone>` "Alarms": importance HIGH, sound `<tone>` (one channel per built-in sound, made when first chosen), vibration;
  - `alarms-<tone>-insistent`: the same with `FLAG_INSISTENT` on its notifications, for "Continuously until cleared";
  - `alarms-silent` "Alarms (silent)": for `alarmSound` off;
  - `summary` "Daily summary": DEFAULT.
  A user-chosen sound gets its own channel `alarms-<hash>`, because Android fixes a channel's sound once created.
- Schedule with `LocalNotifications.schedule` using `schedule.at` + `allowWhileIdle: true` (exact, Doze-safe). On
  Android 12+ check `canScheduleExactAlarms` and, if refused, explain and open the system "Alarms & reminders" page.
  Without exact alarms, notifications may be late; show that in Settings → Alarms.
- After a reboot, the plugin restores scheduled notifications. Verify this, and if it doesn't, add a
  `BOOT_COMPLETED` receiver that starts the background runner job to reschedule.
- Action type `alarm` with actions `snooze`, `done`, `open` (`foreground: true` for open). The listener handles them in
  the host core even when the app was launched by the action.

## Files

`Directory.Data` holds `reminders.ics`, `state.json`, `sounds/`, `backups/`. Android's Auto Backup
includes them (`android:allowBackup="true"`, a `data_extraction_rules.xml` that includes the files and excludes
`*.tmp`). The app can be opened with `.ics` files: an intent filter for `text/calendar` and `*.ics` (ACTION_VIEW and
ACTION_SEND) imports the file after a confirmation ("Import 12 items from family.ics?").

## Build

- `npm run build:web` → `www/` (copy the UI, add the mobile files, bundle `host.js` with esbuild, keep the CSP of
  `index.html`, and add `capacitor:` to `connect-src` only if the plugins need it).
- `npx cap sync android`, then `cd android && ./gradlew assembleDebug` (always) and `./gradlew bundleRelease
  assembleRelease` when `RFA_KEYSTORE`, `RFA_KEYSTORE_PASSWORD`, `RFA_KEY_ALIAS` and `RFA_KEY_PASSWORD` are set. Without a
  keystore, deliver the debug APK and the unsigned release, and say how to sign them.
- The SDK must be downloaded from Google. If the network blocks it, finish everything up to `www/` and the
  `android/` project, run all browser tests, and give the user the exact commands to build on their own machine
  (Android Studio or the command-line tools).
- Reproducibility: record SHA-256 of the APK/AAB. `www/` and `host.js` must be byte-identical across two builds.
